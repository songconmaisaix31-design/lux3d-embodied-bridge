## 正文

AI 生成 3D 模型现在很爽，一句话、一张图，几秒出一个物件。

但我一直有个不舒服的地方：**没人能证明你看到的是同一个世界。**

同一个 prompt 重跑一次，模型就变了；把模型丢进物理仿真，碰撞体也跟着变；之前跑出来的回执，指向的是一个已经不存在的物件。

所以这次参加 Aholo 黑客松，我没做「更炫的生成」，我做的是中间那道没人管的缝：

1. 用 Lux3D 生成物件，导出 GLB；
2. 给它的字节算 sha256，连同三角数、包围盒，记成 `asset_id`；
3. 转成仿真台真正会解析的 STL 网格；
4. 把这个 id 写进机器人描述文件的碰撞体里；
5. 跑采集，拿到 `spec_hash` 和每集指纹；
6. 重跑一次——逐位一致。

改一个资产，id 就变，实验身份跟着变，旧回执不会再被误读。

代码、报告、90 秒演示都开源了（Apache-2.0），一句话就能跑起来：

```
python bridge.py demo
```

仓库：github.com/songconmaisaix31-design/lux3d-embodied-bridge
