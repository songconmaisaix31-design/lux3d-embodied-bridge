## 录制清单（照这个顺序录，剪起来最省时间）

1. Lux3D 生成（**先录好，别现场等**；等太久就剪掉等待段，只留结果出现）
2. `python bridge.py demo` 全流程（一次录完，终端不要有报错）
3. 引擎采集那一段（真实运行，允许掉帧，不要用静态图假装）
4. `python bridge.py verify a.json b.json` 的 MATCH 输出
5. 故意改坏的 DIVERGENCE 输出（这一段最值钱，别省）

## 旁白（可直接照读，约 130 字）

> 3D 生成模型已经能造出很漂亮的世界。问题是，没人能证明你看到的是同一个世界。
> 这是 Aholo Lux3D 刚生成的一个物件。我们给它算了一次哈希，把它转成仿真台能解析的
> 网格，再把资产 id 写进机器人描述里。然后，它掉进物理台，被机械臂抓住，跑出两集。
> 两次运行，逐位一致——这就是回执。改一处，回执就红了。
> 资产，第一次成为实验身份的一部分。

## 不要做的事

- 不要用 AI 生成的「假引擎画面」代替真实运行帧，这条会被一眼看穿；
- 不要在视频里出现 API key、邮箱、真实姓名以外的隐私信息；
- 不要把「成功率」当成卖点——成功率低是诚实的，回执一致才是卖点。
